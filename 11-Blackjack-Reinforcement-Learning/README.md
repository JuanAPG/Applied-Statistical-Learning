# Aprendizaje por refuerzo en Blackjack

Agente Q-learning tabular comparado con políticas de referencia y una solución calculada mediante programación dinámica.

## Reproducción

El entorno utiliza Gymnasium, NumPy y Matplotlib. La generación de videos requiere imageio y un codificador compatible.
