# Applied Statistical Learning & Predictive Modeling

Bienvenido a este repositorio de investigación, el cual contiene una colección de modelos predictivos y análisis estadísticos aplicados a problemas del mundo real. El objetivo de este portafolio es aplicar técnicas de Machine Learning para descubrir patrones, evaluar correlaciones complejas y construir modelos predictivos robustos en los ámbitos de la salud pública, la macroeconomía, la educación y los derechos sociales. La colección abarca dos etapas: una primera dedicada a la inferencia y los modelos de regresión, y una segunda centrada en problemas de clasificación, desde la regresión logística y el análisis discriminante hasta métodos de ensamble, máquinas de vectores de soporte y redes neuronales.

## Índice de Proyectos

1. **[Análisis Exploratorio e Inferencial de Riesgos de Obesidad](./01-Obesity-Health-Risk-Analysis)**
   Estudio de factores de riesgo asociados a niveles de obesidad utilizando características demográficas y hábitos de consumo.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/01_obesity_inference.html)

2. **[Predictores Macroeconómicos y Sociales de la Felicidad Global](./02-Macroeconomic-Happiness-Predictors)**
   Modelado de regresión lineal múltiple para determinar el impacto del Producto Interno Bruto (PIB) per cápita, la esperanza de vida y la corrupción en el índice de felicidad.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/02_macroeconomic_happiness.html)

3. **[Optimización y Predicción de Rendimiento Estudiantil](./03-Student-Performance-Optimization)**
   Construcción de un modelo predictivo con selección de características (*Forward Selection*) y validación cruzada para predecir el éxito académico.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/03_student_performance.html)

4. **[Determinantes Sociodemográficos de la Edad Materna al Nacimiento](./04-Maternal-Age-Determinants)**
   Análisis de microdatos a gran escala e inferencia estadística mediante regresión polinomial para caracterizar los factores de riesgo asociados a la maternidad temprana en México.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/04_maternal_age_determinants.html)

5. **[Clasificación del Riesgo de Embarazo Adolescente](./05-Adolescent-Pregnancy-Risk-Factors)**
   Regresión logística implementada desde cero mediante Newton-Raphson, con validación cruzada estratificada, curva ROC y análisis de razones de momios sobre un problema binario desbalanceado.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/05_adolescent_pregnancy.html)

6. **[Discriminantes Lineales y Árboles de Decisión para Estratificación de Edad Materna](./06-Maternal-Age-Group-Classification)**
   Contraste entre un Análisis Discriminante Lineal programado desde cero y un árbol de decisión con poda por costo-complejidad, sobre un problema multiclase donde la exactitud simple encubre un modelo inservible.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/06_maternal_age_groups.html)

7. **[Comparación de Métodos de Ensamble, Kernel y Redes Neuronales](./07-Ensemble-Methods-Benchmark)**
   Benchmark de Random Forest, Gradient Boosting, SVM con kernel radial y una red neuronal implementada en NumPy, evaluando desempeño predictivo frente a costo computacional y escalabilidad.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/07_ensemble_benchmark.html)

8. **[Clasificación del Registro Tardío de Nacimientos en México](./08-Birth-Registration-Delay)** · *Proyecto final*
   Estudio del derecho a la identidad mediante seis modelos de clasificación, con detección y demostración de fuga de datos, tratamiento de valores faltantes como señal, y contraste de los resultados contra cifras oficiales del CONAPO y el INEGI.
   * **Reporte interactivo:** [Ver reporte en GitHub Pages](https://juanapg.github.io/Applied-Statistical-Learning/08_registration_delay.html)
